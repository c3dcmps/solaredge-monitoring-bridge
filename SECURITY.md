# Security policy

Please do not file a public issue containing credentials, endpoint URLs, local
network details, site identifiers, serial numbers, diagnostic downloads, or
provider responses.

Before a public release, security reports should be sent privately to the
repository owner through GitHub's private vulnerability reporting feature.

The integration is read-only. A report that demonstrates credential leakage,
redirection of the authenticated request, acceptance of a public endpoint,
unbounded response processing, or propagation of non-allowlisted provider data
will be treated as security-sensitive.
